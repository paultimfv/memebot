What it does

Buys brand-new memecoins in the first minute after launch, while the market cap is a few thousand dollars, in small chunks that add up to 1 to 10 million tokens. Then it watches wallet activity to decide when to sell.

How it decides

It skips a launch if the creator holds too much, linked wallets bought in the launch block, or the creator is a known rugger. Once in, it sells on creator selling, early buyers dumping or heavy sell pressure, plus take-profit levels and stops.

What's simulated

The launchpad. Each fake coin secretly follows a script (real pump, rug, slow bleed, dud and others), shown in gold so you can check the bot's read. The bot code itself is the same code that will plug into pump.fun on Solana and PONS on Robinhood Chain.
